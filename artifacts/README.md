# Flight Visualizer Artifacts

This folder provides Flight Visualizer with:
- A standard output location — e.g. for newly generated KML, or saved flight track
  source artifacts (e.g., AeroAPI query responses) used to generate KML.
- A standard input location — e.g., for re-using previously saved flight track source artifacts.  

## Included Examples

Several preloaded flight track source artifacts and their corresponding KML files generated by the
`flightvisualizer` utility are supplied in this folder.  See the discussion about these examples
in [the corresponding documentation](../docs/featured/README.md).
